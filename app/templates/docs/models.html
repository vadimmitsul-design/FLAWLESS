Как считается цена вызова

Себестоимость берётся из собственной таблицы цен сервиса на момент вызова, а не из счёта провайдера. Дальше она превращается в рубли:

Формула
цена = себестоимость_USD × (1 + наценка / 100) × курс_USD_RUB

Наценка и курс вмораживаются в каждый вызов: если завтра курс изменится, вчерашние списания не пересчитаются. История расходов всегда отражает условия, действовавшие в момент запроса.

Запасные модели

У каждого алиаса есть цепочка замен. Если основная модель отвечает ошибкой уровня провайдера — превышен лимит, таймаут, 5xx — запрос автоматически уходит на запасную. Ошибки конфигурации (неверный ключ, несуществующая модель) замену не запускают: повторять их бессмысленно.

Списание считается по той модели, которая реально ответила, а не по запрошенной. В истории вызовов виден фактический исполнитель.

Модель без цены

Если для модели нет действующей строки прайса, вызов отклоняется с кодом 503 и типом model_not_priced ещё до обращения к провайдеру. Это защита: без цены сервис не смог бы посчитать списание.

Что нужно перед стартом

  • аккаунт в Flawless — регистрация занимает минуту;
  • API-ключ — выпускается в личном кабинете;
  • положительный баланс — списание идёт по факту использованных токенов.

Шаг 1. Получить ключ

Зайдите в личный кабинет и выпустите ключ. Ключ вида nh_… показывается один раз — сервис хранит только его хэш и восстановить значение не может. Потеряли — выпустите новый, старый отзовите.

Шаг 2. Пополнить баланс

Баланс ведётся в рублях. Пока приём карт не подключён, пополнение проходит через заявку: вы указываете сумму, переводите деньги, администратор подтверждает поступление. Подробно — в разделе Баланс и списания.

Шаг 3. Первый запрос

Базовый адрес — {{ features.api_base_url }}/v1. Метод совместим с OpenAI Chat Completions, поэтому подойдут официальные SDK: достаточно подменить base_url и ключ.

Terminal
curl {{ features.api_base_url }}/v1/chat/completions \
  -H "Authorization: Bearer $FLAWLESS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "{{ default_model }}",
    "messages": [
      {"role": "user", "content": "Объясни, что такое идемпотентность"}
    ]
  }'

Тот же запрос из Python:

Python
from openai import OpenAI

client = OpenAI(
    api_key="nh_…",
    base_url="{{ features.api_base_url }}/v1",
)

response = client.chat.completions.create(
    model="{{ default_model }}",
    messages=[{"role": "user", "content": "Объясни, что такое идемпотентность"}],
)
print(response.choices[0].message.content)

Ключ — в переменную окружения, не в код. Ключ даёт доступ к вашему балансу: попав в репозиторий, он позволит тратить ваши деньги. Отозвать ключ можно в кабинете в любой момент.

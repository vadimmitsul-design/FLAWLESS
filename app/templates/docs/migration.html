Имена моделей

Имена моделей OpenAI напрямую не принимаются — используется алиас сервиса. Замену удобно спрятать в одну константу.

{% for m in models %} {% endfor %}
Алиас FlawlessЧто за ним стоит
{{ m.alias }}{{ m.vendor }} · {{ m.model }}

Что поддержано

  • chat.completions.create — обычный и потоковый режим;
  • параметры temperature, top_p, max_tokens, stop, response_format, tools, tool_choice, seed и другие из справочника;
  • заголовок Idempotency-Key — у OpenAI его нет, но он спасает от двойного списания при повторе.

Чего пока нет

Честный список, чтобы вы не потратили время на отладку того, что не реализовано:

  • /v1/models — списка моделей через API нет, он есть только на этой странице;
  • /v1/embeddings, /v1/completions, генерация изображений и звука;
  • загрузка файлов и веб-поиск на стороне сервиса.

Программы, которые при подключении сами запрашивают список моделей, каталог автоматически не увидят — в них имя модели указывается вручную.

Проверка после переключения

Сделайте один запрос и загляните в историю вызовов в кабинете: там должны появиться модель, число токенов и сумма списания. Если запись есть — интеграция работает.

Что нужно

  • API-ключ Flawless;
  • положительный баланс;
  • Cursor любой свежей версии.

Настройка

  1. Откройте Settings → Models.
  2. Включите OpenAI API Key и вставьте ключ nh_….
  3. Разверните Override OpenAI Base URL и укажите адрес:
Base URL
{{ features.api_base_url }}/v1
  1. В списке моделей добавьте свою модель с именем-алиасом — например {{ default_model }}. Имена моделей OpenAI (gpt-4o и подобные) у нас не принимаются.
  2. Нажмите Verify. Cursor сделает пробный запрос и запишет его в вашу историю вызовов.

Список доступных моделей Cursor забирает методом GET /v1/models — в нём только модели с действующей ценой, то есть те, которые действительно ответят.

Чего ожидать

Обычный чат и автодополнение по коду работают через наш адрес. Часть возможностей Cursor ходит в собственные сервисы редактора и через сторонний адрес не пойдёт — это ограничение самого Cursor, а не шлюза.

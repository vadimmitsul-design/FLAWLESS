OpenWebUI

Готовый интерфейс чата, который ставится на свой сервер. Подключается как обычный OpenAI-совместимый провайдер.

  1. Откройте Settings → Connections → OpenAI API.
  2. В поле адреса укажите {{ features.api_base_url }}/v1.
  3. В поле ключа вставьте nh_….
  4. Сохраните — список моделей подтянется сам.

Запуск в докере

Terminal
docker run -d -p 3000:8080 \
  -e OPENAI_API_BASE_URL="{{ features.api_base_url }}/v1" \
  -e OPENAI_API_KEY="$FLAWLESS_API_KEY" \
  -v open-webui:/app/backend/data \
  --name open-webui ghcr.io/open-webui/open-webui:main

LibreChat

Настраивается через librechat.yaml как пользовательский провайдер:

librechat.yaml
endpoints:
  custom:
    - name: "Flawless"
      apiKey: "${FLAWLESS_API_KEY}"
      baseURL: "{{ features.api_base_url }}/v1"
      models:
        default: ["{{ default_model }}"]
        fetch: true
      titleConvo: true
      modelDisplayLabel: "Flawless"

fetch: true заставит LibreChat запросить каталог через /v1/models. Если предпочитаете фиксированный список — перечислите алиасы вручную и поставьте fetch: false.

Общее для обоих

  • Расход идёт с общего баланса и попадает в историю вызовов наравне с API.
  • Потолки расхода на ключ действуют и здесь — выдайте интерфейсу отдельный ключ с лимитом.
  • Оба интерфейса опрашивают каталог моделей часто; для него выделен отдельный счётчик частоты, поэтому он не съедает квоту платных вызовов.

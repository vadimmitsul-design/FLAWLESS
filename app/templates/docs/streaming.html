Как включить

Передайте "stream": true. Ответ придёт потоком Server-Sent Events: каждая порция — строка data: с фрагментом в формате OpenAI, а поток закрывается строкой data: [DONE].

Terminal
curl {{ features.api_base_url }}/v1/chat/completions \
  -H "Authorization: Bearer $FLAWLESS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "{{ default_model }}",
    "messages": [{"role": "user", "content": "Напиши хайку про биллинг"}],
    "stream": true
  }'

Из Python

Python
stream = client.chat.completions.create(
    model="{{ default_model }}",
    messages=[{"role": "user", "content": "Напиши хайку про биллинг"}],
    stream=True,
)

for chunk in stream:
    delta = chunk.choices[0].delta.content
    if delta:
        print(delta, end="", flush=True)

Что происходит с деньгами при обрыве

Если клиент закрыл соединение на середине ответа, вызов всё равно закрывается корректно: списывается то, что успело сгенерироваться, остаток резерва возвращается на баланс. Незавершённых «висящих» списаний не остаётся.

Это отдельно проверяется автотестом: обрыв соединения в потоковом режиме — не обычная ошибка, и наивная обработка исключений его не ловит.

Ограничение

Заголовок Idempotency-Key в потоковом режиме не действует: повторить поток из сохранённого ответа невозможно. Для запросов, которые нельзя дублировать, используйте обычный режим.

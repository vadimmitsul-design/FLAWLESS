Официальные SDK OpenAI

Совместимость означает ровно это: работают штатные библиотеки, менять нужно адрес и ключ.

Python
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["FLAWLESS_API_KEY"],
    base_url="{{ features.api_base_url }}/v1",
)

print(client.models.list())
Node.js
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.FLAWLESS_API_KEY,
  baseURL: "{{ features.api_base_url }}/v1",
});

const models = await client.models.list();

Что подойдёт без доработок

Любой клиент, который умеет указывать свой base_url для OpenAI: редакторы кода, интерфейсы чата, фреймворки вроде LangChain и LlamaIndex, самописные скрипты. Нужны только два метода — /v1/chat/completions и /v1/models, оба есть.

Чего пока нет — и почему

Claude Code подключить нельзя. Он ждёт API в формате Anthropic (/v1/messages), а наш шлюз говорит на формате OpenAI. Это не настройка: нужен отдельный метод, переводящий один формат в другой. Мы не добавляем его в список поддерживаемых, пока он действительно не заработает.

По той же причине не заработают клиенты, завязанные на /v1/embeddings, генерацию изображений или загрузку файлов, — этих методов в сервисе нет.

Как проверить подключение

Сделайте один запрос и загляните в историю вызовов в кабинете: там должны появиться модель, число токенов и сумма списания. Если запись есть — клиент подключён правильно.

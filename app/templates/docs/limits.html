Ограничение частоты

На каждый ключ действует ограничение {{ rate_limit_per_window }} запросов за {{ rate_limit_window_seconds }} секунд. Превышение возвращает 429 с типом rate_limit_error. Ограничение применяется и к API, и к веб-чату, и к Telegram.

Потолки расхода

Кроме частоты есть денежные потолки — дневной и месячный. Они существуют на двух уровнях: на аккаунте целиком и отдельно на каждом ключе. Проверяются оба, и превышение любого останавливает запрос до обращения к провайдеру.

JSON
{
  "error": {
    "message": "daily spend limit exceeded for this key",
    "type": "spend_limit_exceeded",
    "scope": "key",
    "limit_rub": "500.0000",
    "spent_rub": "500.1300"
  }
}

Как повторять запросы

На 429 и 503 повтор имеет смысл — с нарастающей задержкой. На 401, 402 и 404 повторять бесполезно: пока не изменится ключ, баланс или имя модели, ответ будет тем же.

Если повторяете запрос, который мог уже выполниться, отправляйте его с прежним Idempotency-Key — тогда второго списания не будет.

Алиас вместо имени провайдера

В запросе указывается короткий алиас — {{ default_model }}, а не длинный идентификатор модели у провайдера. Провайдер выпустит новую версию — алиас останется прежним, и ваш код не придётся трогать.

Запасные модели

У каждого алиаса есть цепочка замен. Перегрузка, таймаут или 5xx у провайдера — запрос уходит на запасную модель. Ошибки конфигурации замену не запускают: повторять их бессмысленно. Списание считается по той модели, которая реально ответила.

Модель без цены не вызывается

Если для модели нет действующей строки прайса, вызов отклоняется с кодом 503 ещё до обращения к провайдеру. Это защита: без цены сервис не смог бы посчитать списание, и вызов оказался бы бесплатным за наш счёт.

Справочник в API

Список моделей отдаётся методом GET /v1/models в формате OpenAI — готовые клиенты вроде Cursor и OpenWebUI подхватывают каталог сами. В нём только модели с действующей ценой.
